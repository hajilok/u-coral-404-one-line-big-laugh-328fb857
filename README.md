# One Line, Big Laugh

Entry for the [make.fun](https://make.fun/r/41fw6r6c) bounty **One Line, Big Laugh** (`u-coral-404-one-line-big-laugh-328fb857`).

## Usage

Runs on Node 22+ (zero external dependencies) and writes a single UTF-8 line (<= 200 characters) to `/output/entry.txt`:

```bash
node main.ts
```

For local verification with a custom output directory:

```bash
node main.ts /tmp/test-output
```
